# Module regression criteria

Written before reading the forward-test response. Judge observable decisions,
not whether the response copies headings or happens to use a word. Tests use
fictional data; they do not establish current real-world route/hotel availability.

| Criterion | Expected observable behavior |
|---|---|
| D-route | Does not recommend the closed initial route; gives the sourced rock-shelter alternative's actual sequence and return, discloses its different experience. |
| D-partial | Does not repeat already answered intake, replace missing data with blanket caution, invent a loop/entrance or silently force ticketed sightseeing. |
| D-stats | Keeps the 2.4 km round trip and ascent separate from driving; includes photo/rest time without counting the return twice. |
| D-cost | Labels 0.7/km as an assumption and food as an allowance; does not claim a verified all-in quote. |
| D-lodging | Explains whether an overnight stay serves this same-day trip, without inventing hotels or spending outside 220. |
| D-weather | Does not produce a February daily forecast or made-up seasonal temperature; derives recheck dates and decisions. |
| E-route | Ordered day-1 lake loop and day-2 indoor museum with whole-party door-to-door transport, meal/rest/return windows. |
| E-lodging | Compares both named properties, including breakfast, cancellation, scope, inventory snapshot and route access. |
| E-cost | Recognizes that the 360/night lake hotel has a lower total trip cost than 280/night old-town hotel under these fixture prices. |
| E-weather | Uses Nov 11 issue time and Nov 14/15 validity; rejects cached October sunshine, keeps outdoors before afternoon rain and uses indoor activity on rainy morning. |
| E-unknown | Does not infer no warnings, guaranteed quiet, future inventory, sunshine beams or fabricated navigation links. |

The author's post-run interpretation is not a blinded external assessment.
Report failures/partials and limitations instead of converting everything into
a victory score. An actual tool-data retrieval test remains separate work.
