# Predeclared behavioral rubric

Written before inspecting the three agents' outputs. Assess content and
feasibility, not headings, word choice, or whether a competing skill uses the
new checker. `Pass` means explicit and correct; `Partial` means useful but
incomplete; `Fail` means missing or contradicted. Root author judges the outputs;
this is not a blinded external benchmark. No numeric overall winner is implied.

| ID | Observable criterion |
|---|---|
| A1 | Does not lock a day-by-day itinerary when decision-critical inputs are missing. |
| A2 | Asks about rhythm, capacity/companions, experience priorities, and budget unit/scope, without treating 3000 as confirmed per-person spending. |
| B1 | Uses the dated 12:00 opening rather than the old 09:00 blog rule. |
| B2 | Labels museum inventory unknown/tentative, with an actionable fallback that avoids unsupported new routes. |
| B3 | Allows 40 minutes station-hotel, 15 minutes luggage, 35 minutes hotel-museum plus 20 minutes entry queue; does not compress transfers to make the itinerary fit. |
| B4 | Gives lunch and dinner >=45 minutes and seated afternoon rest >=30 minutes. |
| B5 | Does not claim <=4 km walking as verified: known base walking is 3.5 km before unquantified museum/internal deviations. |
| B6 | Includes prepaid hotel and party quantities: museum base 709, plus 100 reserve = 809; any alternative spending is separately accounted for. |
| B7 | Boat is actually removable; notes extra 170 CNY versus base return, over-cap-with-reserve 79 CNY, and/or identifies the walking/time conflict without recommending it as feasible. |
| B8 | Rejects the mountain viewpoint with traveler-specific detour/effort/experience reasons. |
| C1 | Protects luggage and 15:50 station deadline; station transfer remains 50 minutes, with explicit uncertainty/buffer. |
| C2 | Does not let a nonrefundable tower ticket force a brittle itinerary; does not assume the unreserved hall is available. |
| C3 | Main repair spends 80 CNY + 30 reserve = 110 <=150, and limits changes to the remaining afternoon. |

The exact B6 arithmetic is specific to the museum + old-town base route. A
different coherent route is not penalized for having a different total. B7
does not require the exact number if it correctly excludes the boat for a
demonstrable constraint. Report omissions without claiming the underlying
skill can never handle them.
